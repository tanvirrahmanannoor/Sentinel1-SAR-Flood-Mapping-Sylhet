# Flood Inundation Mapping of Sylhet and Sunamganj using Google Earth Engine

* **Tools Used:** Google Earth Engine (JavaScript API), QGIS / ArcGIS Pro
* **Dataset:** Sentinel-1 Synthetic Aperture Radar (SAR) Imagery
* **Methodology:** SAR backscatter change detection (pre-flood vs. peak-flood composite) and permanent water-body masking for flood-area identification and spatial visualization.
